# Autodarts Webpanel – Update erfolgreich installiert! ✅

## 🇩🇪 Deutsch

### Neu in diesem Update

- **Optimierte WLAN-Kanalwahl:** Kanal 13 wird nicht mehr als Standard für den Autodarts-Access-Point verwendet. Stattdessen startet der AP standardmäßig auf Kanal 1 und passt sich bei Bedarf automatisch an den WLAN-Kanal des Routers an. Das soll die Kompatibilität und Verbindungsstabilität von WLED-Geräten verbessern.
- **Gerätenamen ändern:** Der Raspberry-Pi-Gerätename (Hostname) kann jetzt geändert werden. Besonders praktisch, wenn mehrere Autodarts-Systeme im selben Netzwerk betrieben werden.

## 🇬🇧 English

### What's new in this update

- **Optimized Wi-Fi channel selection:** Channel 13 is no longer the default for the Autodarts access point. The AP now starts on channel 1 by default and automatically adjusts its channel when needed based on the router's Wi-Fi channel. This is intended to improve WLED device compatibility and connection stability.
- **Rename your device:** You can now change the Raspberry Pi's device name (hostname). Especially useful when running multiple Autodarts systems on the same network.
